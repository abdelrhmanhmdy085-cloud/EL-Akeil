## 2025-05-18 - Semantic Card Buttons for Grid Navigation
**Learning:** Dynamic card items in browsing grids (`.level-card`, `.category-card`) rendered as `<div>` elements with click listeners lack keyboard focusability and screen reader semantic structure. Converting card containers to `<button type="button" class="level-card">` with CSS resets (`border: none`, `padding: 0`, `width: 100%`, `text-align: inherit`, `font-family: inherit`) and explicit `:focus-visible` outline indicators provides instant keyboard interactivity without disturbing the flex/grid visual layout.
**Action:** Always render clickable card-based grid items as semantic `<button type="button">` elements, using descriptive `aria-label`s combining title and item counts, and marking decorative internal icons/arrows with `aria-hidden="true"`.
