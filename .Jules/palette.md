## 2025-05-15 - [Accessible Modal Interactions]
**Learning:** Using semantic <button> elements for cards that trigger actions is essential for keyboard accessibility and screen reader support. Adding aria-labelledby to these buttons ensures that all content within the card is announced when focused.
**Action:** Always prefer <button> over <div> for clickable cards, and use ARIA attributes to link titles and descriptions.

## 2025-05-15 - [Splash Screen Usability]
**Learning:** Long splash screen animations (e.g., 5 seconds) can frustrate repeat users. Providing a "Skip" button improves perceived performance and user control.
**Action:** Include a skip option for any splash screen or long-running introductory animation, and ensure it's accessible.
