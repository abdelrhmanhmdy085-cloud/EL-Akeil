## 2026-01-08 - Accessible Search Location Trigger
**Learning:** Decorative inline location icons (like `📍`) within search input containers are often expected to be interactive triggers (e.g. opening a location picker modal or finding current location). Converting them from static `<div>` tags to semantic `<button type="button">` elements with explicit CSS resets (`appearance: none`, `background: none`, `border: none`, `cursor: pointer`) and focus visible outlines (`:focus-visible`) restores expected interactivity while preserving layout and keyboard accessibility.
**Action:** When working with search inputs containing action icons, ensure they are converted into semantic `<button type="button">` elements with `aria-label` and focus styling rather than non-interactive `<div>` or `<span>` wrappers.
