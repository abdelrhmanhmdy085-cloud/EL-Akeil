## 2026-03-30 - Location Picker Micro-UX & Modal Accessibility
**Learning:** Icon triggers inside search bars (such as location pins) can easily be left as non-interactive `<div>`s without `id` hooks or `aria-label` attributes. Replacing them with semantic `<button type="button">` elements with explicit button resets and `:focus-visible` outlines enables keyboard focusability, screen reader support, and unlocks interactive features like map modals. Furthermore, ensuring modal dialogs include `.modal` base classes alongside `role="dialog"` guarantees correct fixed overlay positioning and background dimming when toggled.
**Action:** When inspecting search inputs or icon triggers, always verify they are semantic buttons with `aria-label`, `:focus-visible` outlines, proper modal container classes, and working event listeners.
